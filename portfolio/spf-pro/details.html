Steel, Pipe and Flange Pro

Last updated: 02 August, 2026

Introduction/Overview

SPF Pro (Steel, Pipe and Flange Pro) is a mobile engineering reference application designed for petrochemical engineers, piping engineers, fabricators, and design professionals. Built for Android, the app provides instant access to thousands of dimensional data points from engineering standards, including pipe dimensions, flange specifications, and a few basic engineering calculations—all available offline for on-site use.

All data points have been hand-verified against printed documents to ensure accuracy and reliability of the information supplied.

Key Features

  • Complete Pipe Dimensions: ASME B36.10 (Carbon Steel) and B36.19 (Stainless Steel) dimensional data with all schedules and sizes
  • Comprehensive Flange Data: ASME B16.5 specifications for Weld Neck, Slip On, and Blind flanges with Raised Face and Flat Face options
  • Unit Flexibility: Switch between Imperial, Metric, and Mixed-Metric unit presets to match project requirements
  • Interactive Diagrams: Dynamic drawings with dimensions for clear visualization
  • Engineering Calculations: Built-in corrosion allowance, milling tolerance, and pipe wall stress calculations
  • Pressure-Temperature Ratings: Temperature-dependent pressure rating calculations for flanges
  • Size Comparison Tool: USC to DN (Diameter Nominal) conversion utility for international projects and easy cross-reference
  • Offline Access: All data available locally without requiring internet connection

How it Works / Usage

SPF Pro features an intuitive interface designed for efficient workflow:

  • Home Screen: Quick access to Pipe, Flanges, Fittings, and Structural sections with clear visual navigation
  • Smart Selection: Dropdown selectors for size, schedule, pressure class, and flange type
  • Real-Time Updates: Diagrams and calculations update instantly as you change selections
  • Customizable Settings: Configure units, decimal places, diagram font sizes, and design parameters to match your preferences
  • Premium Content: In-app purchase system to unlock extended data ranges
